Setup Scanner 1.0.1
-------------------
Productionizes the native-tested v1.0.4 debug scanner logic:
- no PowerShell $PID automatic-variable collision
- Windows PowerShell 5.1-safe array materialization before JSON object construction
- OrderedDictionary-safe product grouping through dictionary indexers
- StrictMode-safe optional Registry FriendlyName/DeviceDesc/Service/Mfg access
- read-only VID_1532 PnP/CIM/SignedDriver/Registry/DriverStore discovery
- no hardcoded Viper/BlackWidow/PID 00C1/02C9/02CC/product 716 requirements
- latest scanner debug JSON/TXT persisted and copied to session Diagnostics

Native pre-release scanner evidence from the user's Windows system:
- Razer Viper V3 Pro discovered as current PID 00C1
- Razer BlackWidow V4 Low-profile HyperSpeed discovered as current PID 02C9
- BlackWidow alternate/historical PID 02CC associated through local Windows metadata
- Setup profile accepted by the v2.2.0 host as 2 products / 3 known connection paths

Setup UI/workflow
-----------------
- Setup is first sidebar view above Status
- Setup view contains only Setup-Scan action; duplicate Systemprüfung action removed
- Systemprüfung is initiated from Status only
- Status start without inventory automatically starts Setup and resumes Health after success
- Setup scanning uses a continuously animated indeterminate cyan progress bar
- Setup timer is stopped on completion and handed cleanly to Health when auto-continuing
