v2.2.6 Setup UI / device-class changes
--------------------------------------
- Current connection PIDs are colored from presentAtScan only.
- presentAtScan=true => Acid Green; known but absent paths => muted.
- Ready summary distinguishes current from all known connection paths.
- Normal Setup scan uses a centered 70%-width Acid-Green indeterminate progress
  bar inside the inventory table.
- The inventory table is alpha-dimmed while the normal Setup scan is running.
- Normal scan text is simplified for end users.
- Setup Scanner 1.0.5 derives generic deviceClass from current PnP evidence,
  preferring the primary HID MI_00 Mouse/Keyboard class and failing closed to
  generic device on ambiguity.
- Inventory rows and the guided calibration dialog display vector mouse /
  keyboard / generic-device glyphs.
- No endpoint PID or product/model constant is used to assign deviceClass.
