v2.3.6 Guided Connection Learning correction
--------------------------------------------
- Wireless learning no longer treats cable removal as sufficient proof for every
  device profile.
- The interaction flow is derived from generic deviceClass evidence and contains
  no product-name or endpoint-PID rules.
- mouse profiles retain event-driven Wireless learning: disconnecting the cable
  may itself be the intentional transition into wireless operation.
- keyboard and conservatively unknown device profiles enter an explicit
  confirmation state after the Wireless baseline. WM_DEVICECHANGE cannot
  auto-complete this state.
- The confirmation prompt supports hardware both with and without a separate
  mode switch. The user establishes the final wireless operating state and then
  explicitly selects "Wireless prüfen".
- The confirmation probe remains native SetupAPI and fails closed unless exactly
  one verified non-wired connection resolves for the selected productKey.
- If a previously learned HIGH wired PID is still present, Wireless confirmation
  is rejected.
- Explicit confirmation persists source user-guided-wireless-confirmation;
  event-driven mouse transitions retain user-guided-wireless-transition.
- Guided completion and guided skip completion no longer launch the full Setup
  PowerShell scan automatically. Existing inventory entries are updated directly;
  a newly discovered but not-yet-materialized PID produces only an advisory for
  a later manual Setup scan.

Native acceptance focus
------------------------
1. Skip both mouse learning steps and learn only the keyboard.
2. Wired: connect the keyboard by cable and verify the wired role is learned.
3. Wireless: start Wireless learning. The wizard must enter the explicit
   confirmation state; unplugging the cable alone must NOT complete learning.
4. Move the keyboard to its actual Wireless mode, then click "Wireless prüfen".
   The learned Wireless source should be user-guided-wireless-confirmation.
5. After completion, close the wizard. SETUP must remain interactive and must not
   start a hidden/full Setup scan automatically.
6. Separately re-test the mouse: after Wireless learning is armed, cable removal
   may still auto-complete the mouse path without requesting a hardware switch.
