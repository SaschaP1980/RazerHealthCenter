Razer Synapse + Chroma Health Center v3.0.7 - Final Build Validation

Scope
-----
v3.0.7 is a narrow reliability patch for the read-only AppEngine user-mode
Diagnostic introduced in v3.0.6. A real Windows PowerShell 5.1 run failed with
System.ArgumentException: Argument types do not match, causing Gate 1 to become
UNKNOWN even though the recovered Razer runtime was functioning correctly.

PowerShell 5.1 compatibility correction
---------------------------------------
- RHC.DIAG.APPENGINE.USERMODE is versioned 1.0.0 -> 1.0.1.
- Active payload: diagnostics/diagnose-appengine-usermode-v1.0.1.ps1.
- Generic Collections.Generic.List containers were removed from the diagnostic.
- Error/process collection now uses native PowerShell arrays end-to-end.
- JSON output uses the native arrays directly, avoiding the observed PS 5.1
  Generic.List materialization/type-binding failure.
- The module remains read-only and keeps the same runtime/launch-contract evidence.
- Registry64/Registry32 handling and all repair semantics remain unchanged.
