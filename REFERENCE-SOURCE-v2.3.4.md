# Reference Source v2.3.4

Canonical source baseline for Razer Synapse + Chroma Health Monitor v2.3.4.

Changes from v2.3.3 are presentation-only in the Setup live-refresh cell: while a known-PID live refresh is active, the PID/role text is not rendered at all. Only the Acid-Green indeterminate sweep is visible in the existing cell band. After refresh completion the verified PID/role text is rendered again with the existing live-presence colors.

No live-presence, product identity, WM_DEVICECHANGE, guided-learning, Health, Repair, persistence, or raw-diagnostic semantics are changed.
