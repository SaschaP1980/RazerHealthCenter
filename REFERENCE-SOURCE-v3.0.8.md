# Reference Source v3.0.8

Canonical source basis for Razer Synapse + Chroma Health Center v3.0.8.

Transient Synapse/Chroma dashboard renderers remain observable but are not normative for background health. Persistent healthy evidence is the validated full Run contract, unambiguous runtime main, systray, background manager, lighting engine and generic device middleware.

All repair safety rules and payloads are unchanged from v3.0.7.
