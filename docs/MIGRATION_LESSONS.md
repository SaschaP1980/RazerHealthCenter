## RHC-20 integration lessons (October 2026)

GitHub-token-created branches and PRs need explicit workflow_dispatch for exact source-head statuses. A Candidate's Linux, Windows and aggregate statuses can all pass while the separate production-Promotion job intentionally fails. Source/ZIP approvals must bind an exact SHA-256 and Owner RHC22 comment; simulated approvals and CI do not stand in for native Razer hardware/rollback. Unknown remote writes must never be retried blindly. An active deletion/force-push ruleset is not active required PR/CI enforcement.
